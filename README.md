# Music.Release
Music Controller

Приложение для управления музыкой через горячие клавиши без переключения между окнами.

Скачать

Последняя версия:

[Скачать Music Controller](https://github.com/ostapenko-Nik/Music.Release/releases/tag/v1.1.0)

Возможности
Play / Pause
Следующий и предыдущий трек
Управление громкостью
Глобальные горячие клавиши
Работа в фоне
Поддержка разных музыкальных сервисов
Поддерживаемые сервисы
Spotify
VK Музыка
YouTube Music
Установка

Скачайте PlayerForGame-v1.1.0-win-x64.zip из последнего релиза, распакуйте всю папку и запустите VKMusicController.exe. Установка .NET не требуется.
