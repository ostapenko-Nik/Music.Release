# Громкость музыки ВКонтакте

Расширение передаёт команды глобальных хоткеев в музыкальный плеер VK.
Системная громкость, игры, Discord и другие вкладки браузера не изменяются.

## Установка один раз

1. В Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку `BrowserExtension` (в ней лежит `manifest.json`). Оставьте папку на постоянном месте.
4. Запустите новую сборку PlayerForGame. Если старая версия уже работает в трее, сначала завершите её через Exit.
5. Откройте VK Музыку и запустите трек. Значок расширения покажет `VK`, когда приложение подключено. `OFF` означает, что приложение не запущено или локальный порт занят. Нажмите значок для проверки.

## Горячие клавиши по умолчанию

- `Ctrl + Alt + ↑` — громче на 5 процентных пунктов.
- `Ctrl + Alt + ↓` — тише на 5 процентных пунктов.
- `Ctrl + Alt + M` — выключить звук VK; повторное нажатие вернёт предыдущую громкость.

Настроить сочетания можно в PlayerForGame → Настройки → Горячие клавиши. Сохранённые изменения применяются сразу. В старой конфигурации новые действия добавляются автоматически. Если стандартное сочетание уже занято другим действием, новое действие будет выключено: назначьте свободную комбинацию и включите его.

Музыка может играть в фоновой вкладке: переключаться из игры в браузер не требуется. Если VK открыт в нескольких вкладках, выбирается играющая; при нескольких одновременно играющих музыкальных плеерах команда отклоняется. Системный звук не используется как запасной вариант.

## Совместимость

Поддерживаются Chrome и Edge на Chromium 120+ и страницы vk.com, vk.ru, music.vk.com, music.vk.ru. Firefox пока не поддерживается.

Основной способ — `getAudioPlayer().setVolume()` и чтение громкости самого плеера VK; для музыкальных страниц с HTML-плеером используется только элемент `audio`. Видео и клипы не затрагиваются. Внутренний интерфейс VK может измениться: если плеер не предоставляет доступную громкость, приложение покажет уведомление, а звук Windows останется прежним.

Расширение использует только разрешения на страницы VK, выполнение функции в плеере и таймер подключения. Оно не обращается к cookies, паролям, сообщениям или токенам. Связь с приложением идёт по WebSocket на `127.0.0.1:43821`, без внешнего сервера. Локальный мост принимает соединения только с origin расширений Chromium.
